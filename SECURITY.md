# Security policy

This is an educational local password-generation demonstration, not a credential vault or audited password manager.

If you find a security defect, please contact the maintainer privately via their [GitHub profile](https://github.com/MatthewAllen1) rather than posting passwords, secrets or sensitive reproduction materials in a public issue.

Known limitations: password display is visible, copied credentials can remain accessible to clipboard-monitoring applications, and local malware or a compromised operating system can access generated output. The application has no storage, network calls or master-password protections.

Do not enter real credentials or publish examples containing private secrets. Use a reviewed password manager for routine credential storage and management.
